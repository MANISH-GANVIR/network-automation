A model is an AI brain that is trained on data
used to perform specific tasks.

An LLM (Large Language Model) is a type of AI model
that is trained on large amounts of text data
to understand and generate human language.

In my automation project, I used Qwen3:8B,
which is an LLM, and Ollama as the platform to run it locally.
The command ollama pull qwen3:8b downloads and installs
the Qwen3:8B model on the local machine, allowing it to be
used offline for tasks such as answering questions,
generating code, and assisting with automation.
